# Validation status

2026-09-18. The local analysis-only trial passed the checks below.

## Scope

The candidate contains 2,149 records and 77 analysis fields, plus newly generated
release identifiers. Its input columns exactly match the combined ML and CLPN
requirements. The package contains no original participant-key mapping, raw
questionnaire files, item-response matrix, unused measurements, or measurement-
scoring program. A text and file-type inspection found no original research
folder paths or questionnaire-read dependencies.

## Numerical reproduction

- Reconstructed inputs reproduced the saved CatBoost test predictions with
  maximum absolute difference 4.4e-16. Observed outcomes matched exactly.
- Seven models were refitted at the retained parameters. The largest absolute
  difference across their training, validation, and test performance metrics was
  8.4e-17.
- Grouped interventional SHAP importance differed by at most 9.7e-17, and the
  top-ten order matched. After including CatBoost's global bias in the prediction
  baseline, the additive prediction check differed by at most 5.2e-8.
- The 30-node CLPN was re-estimated with the original cross-validation sampling
  configuration. Its largest absolute coefficient difference was 2.7e-15;
  all 659 nonzero cross-lagged paths were retained. The largest difference in
  out-, in-, and one-step bridge expected influence was 1.7e-14.
- Every standardized network input cell was compared. The maximum absolute
  preprocessing difference was 6.1e-14.
- Both nonparametric and case-dropping bootstrap execution completed with five
  replicates each. These were execution tests, not inferential reproductions.

## Independent-directory test

Only the candidate folder was copied into a fresh temporary directory. Both
analyses and the bootstrap execution test ran there successfully, without
dependencies on the original project or measurement programs. This was a
clean-directory execution and source-dependency inspection, not an operating-
system access-denial sandbox.

## Remaining boundaries

The original 1,000 + 1,000 bootstrap analyses were not rerun in full. Historical
hyperparameter searches, measurement scoring, item-level reliability, and
pixel-identical figure rendering were not reproduced. The supplied scripts
include the full bootstrap option but do not claim it has been completed here.

These checks were completed before repository publication. Numerical
reproducibility does not establish anonymity. The manuscript and submission
files were not modified. The owner subsequently authorized public GitHub
publication on 2026-09-18. The README describes the scope of this release and
the analyses not regenerated by the supplied scripts.

Machine-readable aggregate results are in `validation_summary.json`.
